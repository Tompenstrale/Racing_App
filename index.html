💾 Data

Save, backup, restore and cloud sync – all data management in one place.

Local data

Data lives in this browser (localStorage). Save writes current edits; Backup exports everything to a JSON file; Restore imports a previous export.

☁ Cloud sync

Push/pull the whole database (all vehicles, runs, settings) to a shared JSON file in a GitHub repository. Any device can pull, edit and push – last push wins, so always pull before editing and push after. The token is stored only on this device.
